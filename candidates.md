# Candidate lines — One Line, Zero Use

Theme: a hilariously useless superpower. Judged on: funny first, payoff in the
last words, fresh angle, tight wording, vivid specific uselessness.

## Candidates

1. I can teleport, but only six inches to the left, and only while sneezing.
2. I can read minds, but only my own, and only what I was thinking yesterday.
3. I can turn invisible, but only when nobody is looking, including cameras.
4. I can talk to houseplants, but they only ever ask me for water.
5. I can predict the weather with perfect accuracy, exactly one day too late.
6. I can hold my breath forever, but only while already underwater and asleep.
7. I can summon any elevator in the building, but it always arrives one floor off.
8. I can remember every license plate I have ever seen, but no faces, names, or where I parked.

## Pick

Candidate 8 — the payoff lands in the very last clause ("where I parked"), the
uselessness is vivid and specific (an enormous, perfect memory that skips the
one detail that matters), and the rhythm sets up a useful-sounding gift before
undercutting it three ways. Tightened below in main.ts.
